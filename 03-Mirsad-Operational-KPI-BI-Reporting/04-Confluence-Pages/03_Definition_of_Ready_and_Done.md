# Definition of Ready and Done

> Simulated portfolio project. Client, people and data are fictional.

**Ready:** story with Gherkin; KPI or rule referenced by ID; source columns identified; sample data available; estimate agreed.

**Done:** code reviewed; unit tests on sample rows pass; DAX parity with the Python output within 0.1 hours; data-quality report generated; definition recorded in the glossary; owner accepted at review.
