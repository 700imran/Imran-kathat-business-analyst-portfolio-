# Support Runbook

> Simulated portfolio project. Client, people and data are fictional.

| Symptom | Check | Action |
|---|---|---|
| Dashboard shows yesterday's data | Refresh history | Re-run refresh; alert BI owner after two failures |
| Quarantine rate above 3% | Quality report reasons | Send to export owner with the reason table |
| KPI differs from Excel | Parity test | Compare pipeline output with DAX measure |
| User sees wrong team | RLS mapping | Check UPN mapping (case-insensitive) |
